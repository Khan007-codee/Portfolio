Case Study

RupXPay

Web3 Crypto-to-INR Mobile Application

What is it?

RupXPay is a personal project I built to learn how a multi-layer application works in practice. The goal was to connect a mobile frontend, a backend API, a database and a Web3 blockchain service — all talking to each other.

The concept: a user connects their Web3 wallet (MetaMask, Trust Wallet), their crypto balance is retrieved and converted to an INR equivalent, they go through a KYC check, and receive an INR payout via UPI.

What I actually did

  • Set up a React Native / Expo mobile app from scratch
  • Built backend REST APIs using Node.js, Express and TypeScript
  • Designed the database schema and used Prisma ORM with SQLite
  • Integrated Web3.js and connected to Ethereum's Sepolia test network via RPC
  • Implemented wallet balance fetching and a crypto-to-INR conversion flow
  • Designed a conceptual KYC flow (Aadhaar, PAN, selfie submission)
  • Built a conceptual UPI payout workflow
  • Created an admin panel for internal data management
  • Debugged frontend-backend integration issues, environment configs and RPC connectivity

What I learned

Most of the technologies in this stack were new to me when I started. I learned TypeScript by writing it, figured out Prisma by reading docs and debugging ORM errors, and understood how blockchain RPC calls work by troubleshooting them when they failed.

The biggest takeaway was understanding how a full-stack application actually holds together — and how much can go wrong between each layer when they're not aligned.
